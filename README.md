# Great Vision Preparatory School Management Portal

This is the browser-based starter version of the Great Vision Preparatory School management portal.

## Publish with GitHub Pages
1. Upload `index.html` to the root of the GitHub repository.
2. Open the repository's **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site. The published address will appear in Settings → Pages.

## Important limitations
- This version is a browser demo. It stores records in the browser's local storage on the device being used.
- It does not yet have a shared online database, secure server-side authentication, or multi-device synchronization.
- Demo accounts are displayed on the login screen. Change/remove these before handling real student information.
- Do not enter real student or parent personal information until a secure backend and proper access controls are implemented.
